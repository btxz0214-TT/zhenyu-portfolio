Behavioral prepayment and deposit runoff, plus forecast-driven new issuance priced at origination in each scenario. Earnings reflect a dynamic book, not a static snapshot.

Rate mechanics, done exactly

ISDA day-count conventions, cubic-spline discount factors, floors, caps, deposit betas and reset rules — built on a yield-curve library I wrote myself.

03 / BUILT WITH AGENTS

I own the rules.
Agents write the code.

GitHub Copilot agents built ~14K lines of Python. I owned what agents can’t: the financial logic, the acceptance criteria and the judgment of when a number is right. Shipped in six weeks as a self-service app, it now serves 10 Treasury and Modeling colleagues.

  1. 01

    Persistent context

    A living playbook records architecture, business rules and lessons from every debugging session, so each agent starts where the last one stopped.

  2. 02

    Non-negotiable guardrails

    Inputs drive results; benchmarks are compare-only. No hardcoding to force a match — unexplained gaps surface as missing business rules.

  3. 03

    Regression gates

    Every change re-runs the full reconciliation. Performance refactors must reproduce prior results to a 10−12 relative tolerance.
